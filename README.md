# AIOS online, by AI Sherpa

One plugin for the Claude app: the AIOS routines (first session, remember, close, new project, it's broken) and thinking tools, for clients who work in Claude Projects with their context as Google Docs in their own Google Drive. Each client's own information lives only in their own Drive and is never in this repository.

In the Claude app: Customize → Plugins → Add → Add marketplace → Add from a repository → `santiagores1986/aisherpa-online` → Sync → Aios online → Add.

Made by [AI Sherpa](https://aisherpa.me).
